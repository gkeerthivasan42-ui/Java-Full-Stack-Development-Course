switch case statement:
========================

def: expression based execution

expression ? var var+1 a+b/c a+c

syntax:
switch(expression)
{
	case value1:
		statement;
		break;
	case value2:
		statement;
		break;
	case value3:
		statement;
		break;
.........................
	default:
		default statement;
}
example:
int k=1
switch(k)
{
 case 1:
	s.o.p("one");
	break;
 case 2:
	s.o.p("two");
	break;
.........
 default:
	s.o.p("Enter correct choice");
	break;
}

variables?
	variable is a user-defined identifier
	Storing data in RAM
	Temporary memory
	
	The value changes during execution of the program.
	ex: RAM, pendrive, memory card
constant:
	The value does not change during execution of the program.
	ex: cd-r-dvd-r
variable naming rules?
	*) Must start with alphabets (a-z) or _(Underscore)
	*) Do not start with a number, but we can use the second letter onwards
	*) Keywords or reserved words are not allowed
	*) Special chars not allowed except_
	*) Variable names must be unique
	*) Spaces not allowed

looping or iterator:
====================

	definition: a set of same statements executes more then one times until condition is true.

	types:
	1) for loop - fixed iteration
	2) while loop - unfixed iteration with entry loop
	3) do.. while loop - unfixed iteration with exit loop
	4) nested loop - a loop within a loop

1) for loop:
============

for(initial; condition; increment/decrement)
{
statement;
}

execution steps:

step 1: initial (starting value)
	ex: int i=1
step 2: condition (true/false)
	ex: i<10
	if true means goto step3
	if false means end loop
step 3: statement
	ex: s.o.p(i)
step 4: increment/decrement
	ex: i++ or i=i+1 or i+=1
step 5: step 2

ex:
for(int i=5;i<17;i+=3)
{
s.o.p(i);
}
o/p: 5 8 11 14
