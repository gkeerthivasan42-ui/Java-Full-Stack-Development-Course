looping or iterator:
====================

	definition: a set of same statements executes more then one times until condition is true.

	types:
	1) for loop - fixed iteration
	2) while loop - unfixed iteration with entry loop
	3) do.. while loop - unfixed iteration with exit loop
	4) nested loop - a loop within a loop

1) for loop:
============

for(initial; condition; increment/decrement)
{
statement;
}

execution steps:

step 1: initial (starting value)
	ex: int i=1
step 2: condition (true/false)
	ex: i<10
	if true means goto step3
	if false means end loop
step 3: statement
	ex: s.o.p(i)
step 4: increment/decrement
	ex: i++ or i=i+1 or i+=1
step 5: step 2

ex:
for(int i=5;i<17;i+=3)
{
s.o.p(i);
}
o/p: 5 8 11 14

What is BODMAS? (Order of Operations)

1. BODMAS is a rule for the order in which maths operations happen
2. It stands for
	1. Brackets
	2. Orders(powers or roots)
	3. Division and Multiplication(Left to right)
	4. Addition and Subtraction (left to right) 

What is an algorithm?
* An algorithm is a step-by-step set of instructions to solve a problem or complete a task.
* In programming, it tells the computer what to do and in what order.
* Analogy: It's like a recipe - clear steps from start to finish.

Visualising Algorithms with Flowcharts

Algorithm Can Be Visual Too

* An algorithm isn't just written in code - it can be shown as a flowchart
* A flowchart is like a map of the steps the computer follows
* Each shape shows a different kind of action (start, input, output, end)

Function
=======

What is a function?

* A Function is a named set of instructions
* It runs a specific task or solves a small part of a bigger problem
* Think of it as a mini-program inside a program

Why use a function?
* Functions help avoid repeating the code
* Instead of copying code again and again, call the function whenever needed
* This makes code cleaner, easier to update, and easier to understand
